# Smart Traffic Violation Detection (Streamlit + YOLOv8)

## Setup
pip install -r requirements.txt
streamlit run app.py

## Files
- app.py            -> complete application
- demo_video.mp4    -> bundled video for trying the app without an upload
- best.pt           -> trained helmet model (generated by train_helmet.py)
- yolov8n.pt        -> downloaded automatically on first run (vehicles, traffic light)
- violations/       -> captured violation photos (auto-created)

## Train the helmet model
`train_helmet.py` downloads the labeled Kaggle Helmet Detection dataset, converts
its Pascal VOC annotations to YOLO format, trains for 50 epochs, and copies
`best.pt` beside `app.py`.

For NVIDIA GPU training on Windows, install the CUDA-enabled PyTorch build first:

```bash
pip install "torch==2.14.1+cu130" "torchvision==0.29.1+cu130" --extra-index-url https://download.pytorch.org/whl/cu130
```

Then install the project requirements and train:

```bash
pip install -r requirements.txt
python train_helmet.py
```

Resume an interrupted run with `python train_helmet.py --resume`.

The model classes are `with helmet` and `without helmet`; the app recognizes
`without helmet` as a violation.

## How it works
Choose **Try the built-in demo** in the app to preview and process `demo_video.mp4`,
or choose **Upload a video** to use your own traffic footage.
1. YOLOv8 + ByteTrack detects/tracks car, bus, truck, motorcycle, bicycle + traffic light.
2. Red light: signal from the traffic-light colour (HSV), or "Always RED"/"Cycle" mode.
   A vehicle is flagged when its bottom edge crosses the stop line while signal is RED.
3. Helmet: custom model finds "no helmet" heads, matched to a tracked motorcycle.
4. Each vehicle is saved only once (track ID) -> photo shown in gallery below the video + CSV log.
